# 2–3 minute demo video script

**0:00 — Problem (20s)**
"Whenever I find an internship or fellowship at 2 AM, I save the link or send it to myself on WhatsApp.
Then I forget. When I finally come back, the deadline has passed. The problem isn't finding opportunities —
it's following through."

**0:20 — Startup brief (20s)** Open the app.
"Every time I open Opportunity Rescue, it gives me a brief: 3 opportunities need attention, 2 expire this week."

**0:40 — Capture + analyze (40s)** + Add opportunity → paste text → Analyze.
"I paste the text from the official page. It pulls out the organization, type, eligibility, skills and deadline —
and shows me exactly which sentence the deadline came from. If a deadline isn't stated, it says so instead of guessing."
Point at NEXT ACTION → Save.

**1:20 — Opportunity Debt + Rescue Mode (40s)** Click Rescue now.
"This is my Opportunity Debt — things I saved but never acted on. Rescue Mode picks the 3 most at-risk and gives
one concrete step for each." Click Done → Started. "A bookmark stores a link. Opportunity Rescue tells you what to do next."

**2:00 — IBM Bob (40s)** Show the bob_sessions screenshots / Bob IDE.
"IBM Bob was my development partner: Ask mode to understand the codebase, Plan mode to prioritize, Agent mode with a
custom opportunity-extractor skill to harden the parser with tests, add calendar export, and fix issues from a
judge-style review."

**2:40 — Close (10s)** "Next: a Chrome extension button and IBM Granite summaries on the same analyzer. Thank you."
